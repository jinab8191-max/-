# 레퍼런스 분석팀

목표: "왜 이 영상은 끝까지 보게 되는가"를 감이 아니라 **숫자와 장면**으로 뽑아서, 편집팀(reels-edit-team)이 그대로 따라 할 수 있는 규칙으로 만든다.

## 0. 입력 받기
- 레퍼런스는 ~/릴스스타일/레퍼런스.txt (한 줄에 링크 하나) 또는 ~/릴스스타일/영상/ 폴더의 파일. 둘 다 없으면 링크를 달라고 한다.
- 추천 개수: 같은 분야·같은 형식(숏폼/롱폼)으로 5~10개. 섞여 있으면 숏폼/롱폼을 나눠서 분석한다.
- 각 영상의 조회수·좋아요·댓글 수를 알 수 있으면 같이 적는다(yt-dlp 메타데이터).

## 1. 내려받기
- yt-dlp 로 ~/릴스스타일/영상/ 에 저장. 인스타그램이 막히면 `--cookies-from-browser chrome` 을 붙인다(크롬에 인스타 로그인 필요). 그래도 안 되면 사용자에게 파일을 그 폴더에 직접 넣어 달라고 한다.
- 분석용으로만 쓴다. 레퍼런스 영상의 화면·소리를 내 영상에 넣지 않는다.

## 2. 영상마다 측정 (숫자로)
| 항목 | 방법 |
|---|---|
| 길이 | ffprobe |
| 컷 수·평균 컷 길이 | ffmpeg `select='gt(scene,0.3)'` 장면 전환 감지 → 컷 간격 평균/최소/최대 |
| 첫 화면 바뀜 | 첫 장면 전환까지 걸린 시간 |
| 말 속도 | whisper-cli 받아쓰기 → 초당 글자 수, 침묵 비율 |
| 훅 | 첫 3초 동안 한 말 원문 + 화면에 뜬 글자 |
| 구성 | 문장을 훅 / 문제 / 본론(목록·스토리) / 반전 / 결론 / 댓글·저장 유도 로 나누고 각 구간 시작 시간 |
| 시각 변화 | 0.5초 간격 프레임을 뽑아(ffmpeg fps=2) 직접 보고: 줌인·줌아웃, 화면 크기 변화, B롤, 이모지·스티커, 화면 분할 |
| 자막 스타일 | 프레임 이미지로 확인: 위치, 줄 수, 글자 수, 강조 단어 색, 테두리, 크기 변화 |
| 소리 | 배경음악 유무·볼륨감, 효과음이 들어가는 순간 종류(whoosh/pop/ding 등) |
| 엔딩 | 마지막 3초 처리(루프로 처음과 이어지는지, 질문으로 끝나는지) |

## 3. 공통점 뽑기
- 영상들에서 **반복되는 패턴**만 규칙으로 만든다. 한 영상에만 있는 건 "선택 기법"으로 따로 적는다.
- 반응(조회수 대비 댓글·저장)이 높은 영상에 더 무게를 둔다.

## 4. 스타일 가이드 작성 → ~/릴스스타일/style-guide.md
아래 형식 그대로, 숫자는 실제 측정값으로 채운다.

```
# 스타일 가이드 (숏폼 | 롱폼) — 분석 영상 N개, 작성일

## 훅 (0~3초)
- 첫 문장 유형: (예: 결과 먼저 / 질문 / 반전 / 숫자)
- 화면 글자 훅: 있음/없음, 위치, 크기
- 첫 시각 변화까지: X초

## 속도
- 평균 컷 길이: X초 (최소 Y, 최대 Z)
- 한 화면이 변화 없이 유지되는 최대 시간: X초
- 침묵 허용: X초 이하

## 시각 변화 (패턴 인터럽트)
- 줌인/줌아웃 비율과 빈도: (예: 컷마다 100% ↔ 115% 번갈아)
- B롤·자료 화면 빈도
- 기타 반복 기법

## 자막
- 위치, 한 줄 글자 수, 줄 수
- 강조 단어 규칙: 어떤 단어를, 어떤 색/크기로
- 폰트 느낌, 테두리/그림자

## 소리
- 배경음악: 장르 느낌, 말 대비 볼륨
- 효과음: 개수/30초, 쓰이는 순간

## 구성 템플릿
- 훅 → … → 엔딩 각 구간 길이 비율

## 엔딩
- 처리 방식

## 선택 기법 (일부 영상만)
- …

## 하지 말 것
- 반응 낮은 영상에서 보인 공통점
```

## 5. 보고
- 영상별 측정 표 1개 + 스타일 가이드 요약 5줄을 보여준다.
- "이제 '편집해줘' 하면 이 가이드대로 편집합니다"라고 알려준다.
- 사용자 본인 영상 중 반응 좋은 것도 넣으면 같이 분석해서 "내 채널에서 먹힌 것" 섹션을 추가한다.
